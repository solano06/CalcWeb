Quick Guide & Key Formulas: Gauss-Jordan Elimination & Rouché–Capelli Theorem

Gauss-Jordan elimination transforms the augmented matrix (A|b) of a linear system Ax = b into its Reduced Row Echelon Form (RREF) via elementary row operations. The Rouché–Capelli theorem classifies existence and uniqueness by comparing rank(A) and rank(A|b).

Rouché–Capelli (Rouché–Frobenius) Theorem

\begin{cases} \operatorname{rg}(A) = \operatorname{rg}(A^*) = n & \implies \text{SCD (Solución única)} \\ \operatorname{rg}(A) = \operatorname{rg}(A^*) < n & \implies \text{SCI (}\infty\text{ soluciones, } n - r \text{ parámetros)} \\ \operatorname{rg}(A) < \operatorname{rg}(A^*) & \implies \text{SI (Incompatible, sin solución)} \end{cases}

Here n is the number of unknowns and r = rank(A) is the number of non-zero pivots.

Elementary Row Operations

F_i \leftrightarrow F_j, \qquad F_i \leftarrow k\cdot F_i \; (k \ne 0), \qquad F_i \leftarrow F_i - \frac{a_{ij}}{a_{jj}}F_j

To eliminate the entry in row i and pivot column j, subtract a_ij / a_jj times pivot row F_j from F_i.

Reduced Row Echelon Form (RREF)

(A\,|\,b) \xrightarrow{\text{Gauss-Jordan}} (I_n\,|\,\vec{x}^*) \quad \text{(cuando } \det(A) \ne 0\text{)}

In RREF, every leading pivot equals 1 and is the only non-zero entry in its column.

Degrees of Freedom in Underdetermined Systems

d = n - \operatorname{rg}(A)

Unknowns whose columns lack a pivot are freely parameterized (λ, μ, ...).

  • Enter each row of the augmented matrix (A|b) separating coefficients with commas and rows with a semicolon ';'. The last number in each row is the constant b_i.
  • If a row of the form (0 0 0 | c) with c ≠ 0 appears during elimination, stop immediately: rank(A) < rank(A|b) and the system is inconsistent.
  • Always swap in a row with a leading 1 as pivot to avoid fractions as long as possible.

Frequently Asked Questions about Linear Systems (Gauss-Jordan)

How do you classify a linear system using the Rouché–Capelli (Rouché–Frobenius) theorem?

Compare rank(A), rank(A|b), and the number of unknowns n. If rank(A) < rank(A|b), the system is Inconsistent (no solution). If rank(A) = rank(A|b) = n, it has a Unique Solution. If rank(A) = rank(A|b) < n, it has Infinitely Many Solutions with n - rank(A) free parameters.

What is the difference between Gaussian elimination and Gauss-Jordan elimination?

Gaussian elimination only zeroes entries below each pivot to reach upper triangular form, whereas Gauss-Jordan elimination normalizes pivots to 1 and zeroes entries both above and below each pivot (RREF).

Which elementary row operations are allowed in Gauss-Jordan elimination?

1) Swapping two rows (Fi ↔ Fj), 2) Multiplying a row by a non-zero scalar (Fi ← k·Fi), and 3) Adding a scalar multiple of one row to another (Fi ← Fi + α·Fj).

How do you identify free variables in an underdetermined system?

In RREF, columns containing a leading 1 pivot correspond to basic variables, whereas columns without a pivot correspond to free parameters (λ, μ).
