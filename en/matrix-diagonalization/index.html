Matrix Diagonalization (2×2 & 3×3)

Detailed computation of the characteristic equation |A - λI| = 0, eigenvalue spectrum, homogeneous linear systems for each eigenspace, modal matrix P, and diagonal matrix D.

Quick Guide & Key Formulas: Spectral Matrix Diagonalization A = P·D·P⁻¹

A square matrix A ∈ ℝ^{n×n} is diagonalizable if and only if ℝ^n admits a basis consisting entirely of eigenvectors of A. In that eigenbasis, the linear transformation simply scales each coordinate axis by its eigenvalue λ_i, enabling instant computation of matrix powers A^k = P·D^k·P⁻¹.

  • Always verify that the sum of all eigenvalues equals trace(A) and their product equals det(A).
  • If all eigenvalues are real and distinct (algebraic multiplicity m_a = 1 each), the matrix is guaranteed to be diagonalizable.
  • When an eigenvalue has algebraic multiplicity m_a = 2, check immediately whether rank(A - λI) = n - 2; otherwise the matrix is defective and requires Jordan form.

Frequently Asked Questions about Matrix Diagonalization

How do you know if a square matrix A is diagonalizable?

A matrix A of size n×n is diagonalizable over ℝ if and only if the sum of algebraic multiplicities of its real eigenvalues equals n, and for every eigenvalue λ_i its geometric multiplicity m_g(λ_i) = n - rank(A - λ_i·I) equals its algebraic multiplicity m_a(λ_i).

How do you construct the modal matrix P and diagonal matrix D?

Place the eigenvalues λ_1, ..., λ_n along the main diagonal of D, and place the corresponding linearly independent eigenvectors v_1, ..., v_n as columns of P in the exact same column order.

Why is every real symmetric matrix diagonalizable?

By the Real Spectral Theorem: every real symmetric matrix (A = A^T) has only real eigenvalues and mutually orthogonal eigenspaces, so it is always orthogonally diagonalizable.

Why is diagonalizing a matrix useful in engineering (A = P·D·P⁻¹)?

It reduces high matrix powers A^k = P·D^k·P⁻¹ and matrix exponentials e^{At} = P·e^{Dt}·P⁻¹ to raising or exponentiating scalar diagonal entries.
